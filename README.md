# CIA Coordinate Remote Viewing (CRV) Skill

A public, SEO-friendly repository containing the Coordinate Remote Viewing (CRV) methodology developed by Ingo Swann and used in the CIA/DIA Stargate/RV research program.

## Overview

This repository documents the structured remote viewing system developed at SRI International under contract to the U.S. intelligence community. It focuses on the Coordinate Remote Viewing (CRV) protocol, the six-stage training progression, monitor rules, ideogram methods, and operational session structure associated with the Stargate program.

The material includes:

- Stage I–VI remote viewing methodology
- Ideogram and sensory contact techniques
- AOL / AI / EI control and reporting
- Monitor and viewer rules
- Operational session structure and training progression
- Historical program references and declassified source context
